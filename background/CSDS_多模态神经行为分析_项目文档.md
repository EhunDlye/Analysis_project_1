# 1. 项目背景与科学问题

抑郁症是全球负担最沉重的精神疾病之一，然而其神经生物学机制仍有很多未解之谜。本项目以慢性社会挥败应激（Chronic
Social Defeat Stress,
CSDS）小鼠模型为核心，综合运用多模态数据采集与分析技术，从多个维度探索抑郁表型的神经与行为关联。

**核心科学问题：**CSDS 慢性应激如何改变小鼠的情感效价（Affective
Valence）加工？能否通过多模态数据融合（面部表情、睡眠电生理、行为学、在体电生理）建立对抑郁表型的预测模型，并揭示其潜在的神经回路机制？慢性应激抑郁造模CSDS前后面部表情的差异精细分析，行为学实验和睡眠数据的差异，通过睡眠数据/EEG数据和行为数据来预测SI指数与抑郁表型，通过Neuropixel探针记录在体电生理活动比较造模前后和不同群之间的神经元活动差异。不同群小鼠（SUS/RES/CTRL）接收不同刺激时的精细面部表情特征，挖掘其中和情绪的关系和潜在神经生物学机制。

## 1.1 研究设计总览

本项目采用"应激前 → 应激后"的纵向对比设计，并结合 CSDS
造模后的易感组（Susceptible）与韧性组（Resilient）横向分组比较。研究分为四大数据模块：

  -------------- ----------------------------------------- -------------------------------------
  **数据模块**   **采集方法**                              **分析目标**
  行为视频       USB摄像头 1080p\@60fps + Arduino同步      面部表情精细分析（FaceMap/DLC）
  舔水行为       Arduino TTP224电容触摸传感器 × 2路        舔水微细结构分析（ILI, Burst Size）
  睡眠/EEG       TDT (Tucker-Davis Technologies) EEG+EMG   睡眠分期、脑电频谱分析
  在体电生理     Neuropixels 探针                          单神经元活动、神经编码分析
  -------------- ----------------------------------------- -------------------------------------

## 1.2 硬件架构与多设备同步方案

本项目采用三台电脑并行工作架构，通过硬件 TTL
脉冲与软件时间戳联合实现毫秒级多模态同步：

**电脑 A（TDT 工作站）：**运行 TDT Synapse 软件，记录 EEG (Ch8) 与 EMG
(Ch7) 高频时间序列信号。TDT 作为全局主时钟（Master Clock），通过其 C0
输出端口以 1Hz 频率向 Arduino 发送周期性 TTL
同步脉冲，用于校正时钟漂移。

**电脑 B（视频 + Arduino 工作站）：**运行 Python
多线程录制脚本（VideoRecord.py），同时采集 1080p\@60fps 行为视频与
Arduino 串口舔水事件流。Arduino Mega 作为关键枚纽，接收 TDT
同步信号（D44 引脚）、检测舔水事件、控制 LED 闪烁（D7
引脚）以提供视觉同步标记，并通过 TTL 输出（D40 引脚）将舔水事件反馈给
TDT 系统。

**电脑 C（Neuropixels 工作站）：**运行 SpikeGLX
软件进行大规模在体神经元记录。通过接收 TDT 和 Arduino 的 TTL
同步脉冲，将电生理数据与其他模态对齐。

## 1.4 时间戳同步技术详解

多模态数据同步是本项目的技术难点与核心创新点。由于不同设备的时钟源存在微小的物理差异（时钟漂移，Clock
Drift），我们采用了"硬件 TTL 脉冲 + 线性回归校正"的混合同步策略：

+----------------------------------------------------------------------+
| **同步原理：线性回归时间偏移校正**                                   |
|                                                                      |
| TDT 以固定频率（1Hz）发送 SYNC_PULSE 至 Arduino。Arduino             |
| 同时记录其本地 millis() 时间戳和 Python                              |
| 系统时间戳（perf_counter()）。通过对数百                             |
| 个同步脉冲时间对进行线性回归拟合，就可以建立两套时钟之间的精确映射关 |
| 系，将任意一个时间点从一个时钟域无损转换到另一个时钟域。残差通常小于 |
| 1ms。                                                                |
+----------------------------------------------------------------------+

## 1.5 面部表情分析框架

基于 Dolensek 等人 (2020, Science)
的里程碑研究，小鼠的面部表情是其内在情感效价（Internal Affective
State）的直接读数。本项目利用 FaceMap GUI
软件提取视频中小鼠的面部关键点坐标，包括：

-   **瞳孔直径（Pupil
    Diameter）：**反映自主神经系统兴奋性，与情绪唤起（Arousal）密切相关

-   **胡须运动位移（Whisker
    Movement）：**多根胡须的帧间运动幅度，反映触觉探索行为和情绪状态

-   **鼻尖运动（Nose Tip Movement）：**反映嘴部区域的运动模式变化

这些特征与舔水率、EEG 频谱、EMG 包络在同一时间轴上对齐展示，并计算跨模态
Pearson 相关系数矩阵，探索各信号之间的关联性。

# 4. 实验范式对比分析

根据您的研究目标------探索 CSDS
慢性应激如何改变小鼠的情感效价加工------我们对两套实验范式进行了系统对比。

## 4.1 范式一：双水嘴经典舔水范式（touchsensor.ino v6.10）

**核心设计：**双路水嘴（S1/S2）的自由舔水范式，类似于经典的糖水偏好测试（Sucrose
Preference Test,
SPT）。小鼠在两个水嘴之间自由选择，每次舔水触发奖励后进入 8s
试次间歇（ITI）。最多 150 次奖励。

**优势：**

-   数据采集系统已全面验证，流水线成熟稳定，已积累大量实验数据（如
    3.09--3.13 多个 Session）

-   舔水检测算法先进，双锁防抖机制确保数据干净，能够捕获高质量的舔水微细结构

-   与 TDT 电生理的硬件同步已经实现，能够进行舔水关联的 EEG 分析

**局限性：**

-   仅能提供二元选择结果，缺乏情感效价的维度广度（Valence Breadth）

-   无法区分"快感缺失（Anhedonia）"与"负性敏化（Aversive
    Sensitization）"的独立贡献

-   不包含厨恶性刺激和物理痛觉刺激，无法构建完整的情感谱系

## 4.2 范式二：多味觉刺激 + 电击范式（MultiStimShockParadigm.ino v2.1）

**核心设计：**基于 Dolensek 等人 (2020, Science) 的理论框架，包含 5
种刺激类型：糖水（正性感受）、水（中性）、生理盐水（中性）、奎宁（苦味厨恶）、电击（物理痛觉）。支持自动化随机序列模式，试次间歇
8--12s 随机化。

**优势：**

-   **多维度效价映射：**能够构建从 -1 (Aversive) 到 +1 (Appetitive)
    的完整情感谱系曲线，而不仅仅是二元偏好

-   **应激影响的双向验证：**可以同时检测 Stressed
    组对糖水的愉悦表情是否铝化（Blunting），以及对奎宁/电击的负性反应是否敏化（Sensitization）

-   **文献支撑强：**直接基于 Science
    年度里程碑研究的实验设计，方法学严谨性高

**局限性与待改进点：**

-   硬件更复杂（需要 4 路电磁阀 + 1 路电击触发器），调试工作量更大

-   代码中的 delay()
    阻塞调用会影响舔水检测的实时性，需要重构为非阻塞架构

-   自动模式中电击可预测性太强，可能导致小鼠进入冻结状态（Freezing），干扰后续舔水数据

-   缺少刺激前基线预捕获期（Pre-stimulus Baseline），不利于表情 AI
    分析的基准校准

## 4.3 范式对比总结表

  -------------- ---------------------- -------------------------------------
  **对比维度**   **范式一（双水嘴）**   **范式二（多刺激 + 电击）**
  情感谱系覆盖   仅正性/中性            正性 → 中性 → 负性 → 痛觉（全谱系）
  核心指标       偏好比 + 舔水率        效价曲线 + 多维表情特征
  文献支撑       经典 SPT 范式          Dolensek 2020 Science
  硬件复杂度     低（2路电磁阀）        高（4路电磁阀 + 电击器）
  代码成熟度     已全面验证             需要重构优化
  数据积累       已有多 Session 数据    尚无
  适用场景       快感缺失检测           情感效价全谱系检测
  -------------- ---------------------- -------------------------------------

# 5. 范式建议：分阶段双范式策略

+----------------------------------------------------------------------+
| **核心结论：建议采用"分阶段双范式"策略**                             |
|                                                                      |
| 在您的研究中，两套范式并不是互斥关系，而是互补关系。范式             |
| 一是已经验证的"地基"，范式二是最终的"科学高度"。建议分三个阶段推进。 |
+----------------------------------------------------------------------+

## 5.1 第一阶段：先用范式一完成数据积累与流水线验证

范式一的代码和硬件已经完全成熟，应当优先利用这个优势：

-   继续积累 CSDS 前后的双水嘴行为数据，完善 batch_pipeline.py
    批处理流水线

-   完成多动物多天的舔水微细结构分析（ILI、Burst Size），建立行为学基线

-   完成 FaceMap/DLC
    面部表情提取的全流程验证，确定表情特征提取的稳定性和可重复性

-   发表第一篇数据驱动的工作（如 CSDS 前后的 SPT 偏好变化 +
    面部表情关联分析）

## 5.2 第二阶段：并行重构范式二代码，补强实验设计

在第一阶段积累数据的同时，并行对 MultiStimShockParadigm.ino
进行关键重构：

1.  **消除 delay()
    阻塞：**将所有电磁阀和电击控制改为非阻塞式状态机，确保舔水检测的实时性不受刺激发放影响。

2.  **增加基线预捕获期：**在每个 Trial 开始前增加 3s
    的静默期（Pre-stimulus Baseline），为 AI 表情分析提供中性对照。

3.  **优化电击策略：**采用 Block 设计（例如：液体 Block → 电击 Trial →
    液体 Block），降低电击的可预测性，避免 Freezing 效应。

4.  **移植双锁算法：**将 touchsensor.ino 中已验证的边缘检测 +
    生理不应期双锁机制移植到新范式中。

## 5.3 第三阶段：采用范式二进行全谱系情感效价研究

当范式二的硬件和代码都经过充分验证后，将其应用于正式实验：

-   在 CSDS
    造模前后分别进行多刺激表情测试，构建每只小鼠的完整效价谱系曲线

-   比较易感组 vs
    韧性组的表情效价曲线差异（是正性铝化还是负性敏化，或两者兼有）

-   结合 Neuropixels
    在体记录，探索特定脑区在不同刺激时的神经元活动模式差异

## 5.4 统计方法建议

+----------------------------------------------------------------------+
| **统计模型推荐：线性混合效应模型（LMM）**                            |
|                                                                      |
| 由于每只小鼠会产生数千帧数据，存在明显的嵌套结构（多帧 ⊆ 多 Trial ⊆  |
| 单只小鼠）。严禁使用普通 t-test 或                                   |
| ANOVA。应采用线性混合效应模型（Linear Mixed-Effects Models,          |
| LMMs），将 Stimulus_Type 和 Stress_Group 作为固定效应，Mouse_ID      |
| 作为随机效应。Python 中可使用 statsmodels.formula.api.mixedlm() 或 R |
